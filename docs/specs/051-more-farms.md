# 051. More farms

- **Status:** Approved
- **Bounded context(s):** farms (content), UI (farm contact links), shared (SEO TSDoc), content docs
- **Related:** specs 019 (organic), 021 (real farms), 030 (farm pages), 029 (region pages);
  `docs/CONTENT-GUIDE.md` „Add a farm“

## 1. Goal

The site lists only 10 farms in 7 provinces, so most produce and region pages show few or no
local growers. The owner asked for as many real farms as possible from any source, with no
invented data and without gradinata.bg as a source. This spec adds 39 real farms (49 in total,
in 20 provinces), each fact re-checked on the cited page on 2026-11-13, and the first farm with a
verified organic certificate.

## 2. User stories

- As a shopper, I want a produce or region page to show more local growers I can reach.
- As a careful reader, I want to see where a farm's facts come from, and which statements come
  from a directory profile or from the farm itself rather than from a check by the site.
- As the owner, I want every new farm to cite the pages its facts come from, so I can review it.

## 3. Scope

### In scope

- **Data:** 39 new files in `src/data/farms/` (list and sources in section 5).
  - **Tier A** (own website or shop, organic certificate, or a current Хранкооп listing priced in
    € in November 2026): 11 farms.
  - **Tier B** (LocalStore.bg producer profile only, fetched on 2026-11-13, naming at least one
    site produce): 23 farms.
  - **Tier C promoted** (in the research notes as „incomplete“ only because the profile shows no
    clear contact): 5 farms whose profile names a site produce. A profile link is a usable
    contact (see section 5).
- **Organic:** ВКУСнаГРАДИНА gets an `organic` block from its COSMOCERT certificate, published
  in the EU TRACES directory and linked from the farm's own „Био земеделие“ page.
- **Tests:** a content test for the new data; the spec-019 test that allowed no farm an
  `organic` block becomes „only farms with a certificate verified in a spec“.
- **Docs:** `docs/CONTENT-GUIDE.md` (farm section and the content-review note on farms).
- **UI (QA finding, decided by the coordinator):** a website link that is a LocalStore.bg or
  Хранкооп profile is named „Профил на <farm> в <directory>“ instead of „Уебсайт на <farm>“, so the
  link purpose is accurate (WCAG 2.4.4). `directoryName(url)` in
  `src/components/farms/directoryName.ts` maps a host to a directory name through the named
  constant `DIRECTORY_NAMES` (`localstore.bg` → „LocalStore.bg“, `coop.hrankoop.com` →
  „Хранкооп“) and returns `undefined` for any other host; `ui.produce.farms.directoryProfile`
  builds the label; `FarmContacts.astro` picks the label. The TSDoc of
  `LocalBusinessJsonLdInput.website` says the value may be a directory profile.

### Out of scope

- Any schema change, and any UI change beyond the contact link label.
- Produce or region pages with many farm cards (e.g. 13 for tomatoes): a follow-up issue.
- Phone numbers that a directory shows masked („088 72* ****“ with „покажи“). They are not
  published, even though the full number is in the page source.
- Farms with no site produce named, no location, or no reachable page (section 5, skipped list).
- New produce ids (hazelnuts, raspberries, blueberries, melons are named by some farms; only
  existing ids are used).

## 4. Domain model

No change. Each new entry follows `farmSchema` (`src/contexts/farms/infrastructure/schemas.ts`):
`name`, `region`, `produce` (≥ 1 existing produce id), `description`, `contact` (at least one of
website, email, phone), optional `address`, `sources` (≥ 1 https URL), optional `organic`
(`certifier`, `certificateId`, `validUntil`). The file name is `Slug.fromBulgarian(name)`.

## 5. Behaviour and edge cases

### Data rules

1. **Sources.** Every fact (province, produce, description, contacts, address) comes from a page
   listed in `sources`, fetched on 2026-11-13. gradinata.bg is never a source.
2. **Contacts.** A website, e-mail or phone is published only when a cited page shows it in clear
   text. LocalStore.bg masks every phone („088 68* ****“), so no LocalStore phone is published.
   A farm without an own site gets as `contact.website` its Хранкооп producer page when it sells
   there (the page is the farm's shop on the cooperative's platform), otherwise its LocalStore.bg
   profile. The schema accepts this, as a website alone satisfies `contact`.
3. **Wording.** A description that rests only on a LocalStore.bg profile starts with „По данни на
   LocalStore.bg …“. A LocalStore fact in a farm with other sources is introduced the same way.
   What a farm says about itself and the site has not checked (organic, GLOBALG.A.P., „без
   химикали“) is worded „По данни на фермата …“. Paused sales are noted with the month of the
   check („към ноември 2026 г.“).
4. **Organic.** Only ВКУСнаГРАДИНА has an `organic` block. No other farm gets one: Комосс,
   Покрайна, Снежана Коцева and Градини Девар only state that they are certified.
5. **Province.** Taken from the source when it names the province, the municipality or a nearby
   city; otherwise from the settlement when the settlement name is unique in Bulgaria (checked on
   bg.wikipedia.org) or the source's context removes the ambiguity. The table says which.
6. **Produce.** Only existing produce ids the source names as grown or sold. A product named only
   as processed (jam, juice, dried fruit) is not listed, because the farm cards appear on pages
   about fresh seasonal produce. Calladan, which sells only dried fruit, is therefore skipped, and
   Комосс does not list plums (its only plums are dried).

### Contact link label

A farm without its own website links its Хранкооп or LocalStore.bg page. That link is named
„Профил на <farm> в Хранкооп“ or „Профил на <farm> в LocalStore.bg“; a farm's own site keeps
„Уебсайт на <farm>“. A host other than `localstore.bg` and `coop.hrankoop.com` (with or without
`www.`) is treated as the farm's own site.

### Edge cases

- A product sold only processed (dried fruit, juice, Hot Farm's sauces) is not listed.
- Two farms share a name root („Чиста храна от „Ранчото““ in Ловеч and „Ферма „Ранчото““ in
  Плевен); their ids differ and both are kept.
- The organic label appears while the certificate is valid (`Farm.isOrganicOn`, spec 019); it
  expires on 2027-07-20.

## 6. Accessibility requirements

No new markup. New farm cards and pages reuse the components of specs 019 and 030 (headings,
lists, links whose accessible name includes the farm name, WCAG 1.3.1). A directory profile link
is named „Профил на <farm> в <directory>“ so its purpose is clear from the link text (WCAG
2.4.4); a farm's own site keeps „Уебсайт на <farm>“. Farm and region pages must
stay free of axe violations and readable without CSS. Brand names written in Latin script
(Vega Fruits, Zizu Peppers, PapiAgro, Pura Vida Organic Farm, Our Garden, Biotiful,
Hot Farm) are proper names, not foreign-language passages, so they get no `lang` attribute.

## 7. SEO requirements

Each new farm gets a `/fermi/<id>` page through spec 030 with a title ≤ 60 characters and a
description of 70–160 characters (`ui.farms.pageDescription`, checked for every farm by
`tests/unit/i18n/farmMeta.test.ts`), canonical URL and `LocalBusiness` JSON-LD. The new farms add
internal links from produce and region pages to farm pages and back.

## 8. Acceptance criteria

1. **AC1:** Given the farm data, when it is read, then all 39 farms of section 5 exist and the
   site has at least 49 farms in at least 20 provinces.
2. **AC2:** Given any farm, when its sources are read, then it has at least one source, every
   source is an https URL, and no source or contact is on gradinata.bg.
3. **AC3:** Given the farm data files, when they are read as text, then no file contains `*`
   (no masked phone number is published).
4. **AC4:** Given a new farm, when its region and produce are checked, then the region exists in
   `src/data/regions/` and every produce id exists in `src/data/produce/`, and its file name is the
   slug of its name.
5. **AC5:** Given a new farm whose sources are all on localstore.bg, when its entry is read, then
   its description contains „По данни на LocalStore.bg“, it has no phone and no e-mail, and its
   website is one of its sources.
6. **AC6:** Given a new farm whose sources are all on localstore.bg or coop.hrankoop.com, when its
   contact is read, then it has no phone and no e-mail and its website is one of its sources.
7. **AC7:** Given the farm data, when the organic blocks are read, then only ВКУСнаГРАДИНА has
   one: certifier „COSMOCERT (BG-BIO-18)“, certificate „BG-BIO-18.100-0004936.2026.001“, valid
   until 2027-07-20, and its sources include the TRACES certificate URL.
8. **AC8:** Given a farm that states it is certified without a verified certificate (Комосс,
   Покрайна, Снежана Коцева, Градини Девар), when its description is read, then every sentence
   with the claim contains „По данни на фермата“ before the claim.
9. **AC9:** Given the built site, when `/fermi/vkusnagradina` is opened, then it shows the label
   „Био · COSMOCERT (BG-BIO-18)“; when `/regioni/razgrad` is opened, then it lists „Оранжерии
   Паскалев“ with a link to its farm page; both pages have no axe violations.
10. **AC10:** Given a farm whose website is a LocalStore.bg or Хранкооп page, when its contacts
    are rendered, then the link's accessible name is „Профил на <farm> в LocalStore.bg“ or
    „Профил на <farm> в Хранкооп“; given a farm with its own site, the name stays „Уебсайт на
    <farm>“. `directoryName` returns `undefined` for any host that is not a known directory.
11. **AC11 (QA):** Given the farm data, then no farm rests only on dried fruit (Calladan is not
    listed, Комосс has no `slivi`), the Hot Farm description does not mention pickles, ЗП Снежана
    Коцева reads „стопанство от 5 декара … регистрирано за ябълки и други трайни насаждения“, and
    Ферма „Бесика“ has the address „с. Бяга, обл. Пазарджик“.
