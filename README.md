# Sezon

Seasonal fruits, vegetables and herbs in Bulgaria: what is in season now, where it grows
best, nutrition facts, preparation tips, traditional uses, and local farms.

The website is in Bulgarian; everything in this repository is in English.

- How we work (for humans and AI agents): [`AGENTS.md`](AGENTS.md)
- Roadmap and concept: [`docs/PLAN.md`](docs/PLAN.md)
- Feature specs: [`docs/specs/`](docs/specs)
- Architecture decisions: [`docs/ADR/`](docs/ADR)

## Quick start

```bash
pnpm install
pnpm dev        # http://localhost:4321
pnpm verify     # lint, types, tests, build, HTML validation, e2e + axe
```
